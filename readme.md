## ⬇️ 下载安装（Windows）

去 [Releases](https://github.com/PeterWilsono/Hoshiori/releases/latest) 下载 **`Hoshiori-Setup-2.1.2.exe`**，双击安装。

- 安装到哪里由你决定：默认会挑一块**非系统盘**（比如 `D:\Hoshiori`），也可以点「浏览…」换地方
- 装完桌面和开始菜单会有快捷方式，Windows「应用和功能」里能直接卸载
- 卸载只删程序，你的对话和设置留在数据目录里，不会丢
- 不想装也行：同一页还有 `Hoshiori-2.1.2-win64.zip`（解压即用）和 `Hoshiori.exe`（单文件便携）

| 文件 | 适合谁 | 启动速度 |
| --- | --- | --- |
| **`Hoshiori-Setup-2.1.2.exe`**（推荐） | 想要快捷方式、想从系统里干净卸载 | 约 5 秒 |
| `Hoshiori-2.1.2-win64.zip` | 不想装、解压就用 | 约 5 秒 |
| `Hoshiori.exe` | 只带一个文件到处跑 | 每次启动要先解压，约 25 秒 |

> 安装包约 164MB。比上一版大了 40MB，因为内置了本地语义模型（24MB）和 ONNX 运行时。
> 换来的是记忆检索能听懂"意思"而不只是"字面"，且不联网、不花 token。

**系统要求**：Windows 10 1809 或更新（需要 WebView2，Win11 自带）；内存 4GB 以上
（语义模型常驻约 200MB）；不需要显卡，也不需要单独下载模型。

关于启动速度：目录版（安装包/zip）不用解压，双击到能聊天大约 5 秒；
单文件版是 PyInstaller 的机制，**每次**启动都要把几十 MB 运行时解到临时目录。

打开后的第一屏是一个会转的星形标识 + 一条进度线 + 一句“正在整理她的房间…”，
进度是真的（主题、存档、Live2D 各过一关就往前一格），不是装样子的转圈。

### 她能表现情绪了

这一版重做了表情系统。她会因为你说的话变成：愉悦（眼睛笑成月牙 + 星星眼）、低落（眼皮垮下来 + 眉尾下垂 + 泪汪汪）、
愠怒（眉毛压低 + 黑脸）、羞怯（脸红 + 偏头 + 抿嘴）、惊讶（睁大眼 + 张嘴）、心动（爱心眼）。

情绪的**幅度**还会跟着强度变——同样一句“开心”，很开心里表情会夸张一些。
她的视线照样跟着你的鼠标走，点她不同部位有不同反应，可以按住抚摸。

### 数据存在哪

默认自动挑一块**非系统盘**（例如 `D:\HoshioriData`），不往 C 盘塞。
想换地方就去 ⚙ → 存储 → 更改位置，现有的对话会一起搬过去，重启后生效。

- 系统要求：Windows 10/11 64 位（WebView2 一般系统自带；没有时会自动退回 Edge 应用窗口）

## 📖 项目简介

**星织（Hoshiori）** 是一个开源的AI陪伴助手，她不仅仅是一个聊天机器人，更是一个有情感、有记忆、能共情的虚拟伙伴。

星织拥有银色的长发和蓝色的大眼睛，穿着校园制服，通过Live2D技术呈现生动的表情和动作。她能够记住你们的对话，理解你的情绪，并在交互中不断成长。

### 为什么选择星织？

- 💝 **情感陪伴**：不是冷冰冰的问答机器，而是有温度的伙伴
- 🧠 **智能记忆**：记住重要信息，越聊越懂你
- 🎭 **情绪共鸣**：根据对话内容实时调整情绪状态
- 🎨 **视觉呈现**：Live2D立绘让交互更生动
- 🔒 **隐私保护**：支持本地部署，数据完全掌握在自己手中
- 🚀 **灵活配置**：支持多种AI模型，可在线可本地

## 🌙 2.1：她会先开口了

2.0 让她"记得更准、回得更快"。2.1 补的是两件更基础的事。

**她有自己的日子。**

不是一句设定，是每天真的记一本流水：几点醒了、吃了什么、翻到哪一页、
什么时候又趴回去睡。一天分几次写，所以你上午问和晚上问，她说的是不同的
事；写的时候会带上你提过的东西，所以你问起，她答得具体——

```
09:30  被消息震醒，头发翘着去关窗            （才九点半啊）
10:15  窝在桌前吃鸡蛋三明治，配凉掉的牛奶      （牛奶忘了热，算了）
11:40  翻上次他说过的那本推理小说，读了两页    （他看到哪儿了来着）
13:05  趴回床上补觉，被窗帘缝里的光晃醒        （一下子就这个点了）
```

光室左下角有一行「她此刻在做什么」，点开是「她今天」的完整时间线。
她说"我刚在看书"，库里就真的有那一条。换一个角色描述，她的日子跟着变。

**她会先开口。**

以前她只在**你说话的时候**才算"想不想找你"，算完往回复尾巴上补一句——
那不叫主动。现在是真的定时器：距你上次说话超过设定间隔、不在静音时段、
今天还没说够，她就会自己说一句。

开口的由头按优先级挑：她今天想跟你说的一句话 → 她做的事里跟你有关的那条 →
上次没聊完的事 → 单纯很久没联系。话是现写的，不是模板：

> 阿哲，报表赶完没？
>
> 上次说的面试没过那事，后来有动静了吗？
>
> 今天风好大，云跑得比谁都急。我刚煮了碗面，蛋黄没煮透，凑合吃。

**默认关。** 会打扰人的功能不该替你做决定。设置 → 日常里打开，
可以调「多久没说话才找」「一天最多几句」「不打扰的时段」（跨零点也认），
还有一个「现在试一句」当场看效果。

她的那条消息会出现一个暖色的「她先开口」标签，跟回复区分开。

### 前端这一版补了什么

对着获奖作品逐条看，差距不在审美，在细节密度：

- **字号**：原来 39 处正文是 8–11px（照着 150% 缩放调的），100% 下会糊。
  统一抬到 11.5–12.5px，层次关系不变
- **反馈动效**：以前动效全是氛围型的（星尘、呼吸、光晕），操作结果没有任何
  反馈。现在发送按钮会转圈、成功打勾、失败抖一下并把内容还回输入框
- **全库搜索**（`Ctrl+F`）：跨所有对话搜，↑↓ 选择，Enter 跳过去并高亮那句话
- **改一下重发**：鼠标移到你说过的那条上会浮出一支笔，改完发送会**真的替换**
  那一条和它之后的内容，不是在下面再叠一条
- **记忆可以改了**：以前只能整条删，把对的那一半也丢了
- **弹窗内边距、快捷问题对齐**：历史列表不再贴着卡片边，四个 chips 改成等宽两列

## 🎭 2.0 里她哪里不一样了

这一版没加新面板，改的是"相处起来像不像一个人"。

**她真的记得，不是假装记得。**
以前按关键词找记忆："老板发火"和"和主管关系不好"字面毫无重叠，找不到。
现在句子会被换成 512 维向量（本地 bge-small-zh，24MB，CPU 跑），
意思近的就能捞出来。同一批测试问法，召回从 6/10 提到 9/10。

**她对你有一套看法，不只是流水账。**
每攒一批对话，她会顺手沉淀一两条"理解"——"他嘴上说没事，其实是怕拖累同事"。
这是"记得住事"和"认识一个人"的区别。

**她说话更像在打字。**
一轮分成两三条发出来，短的可以只有"嗯"，语气跟着当天的心情走，
不会每句都追问、不会突然变成客服。心情有惯性——上一条的不开心会留一会儿。

**她回得更快了。**
首字延迟 27 秒 → 2 秒（关掉推理模型的默认思考），整轮 32 秒 → 4 秒。

**更省。**
提示词拆成"不变的"和"每轮变的"两段，不变的放最前面吃缓存；
历史窗口从"每轮滑动"改成"攒一批整体前移"。
同一个会话聊到第二十轮，可复用的前缀从 1% 变成接近 100%。

**她会认真对待不该开玩笑的话。**
自伤类表述用本地规则识别，命中不会拦你的消息、不会审查，
只是让这一轮的语气收起来——别接梗、别讲道理，先问你人在哪儿。

**你的东西都在本地。**
对话、记忆、向量、情绪状态全在 SQLite 里，模型也在自己机器上跑。
除了调大模型那一次请求，没有任何东西出过这台电脑。

## ✨ 功能特性

### 🎯 核心功能

#### 1. 智能对话系统
- 支持多种AI模型（DeepSeek、小米MiMo、本地模型等）
- **思考模式可开关**（默认关）：聊天要的是快，实测关掉后首字从 27 秒降到 2 秒；
  需要她认真想一件事时再打开
- 联网搜索功能，获取实时信息
- **附件上传**：Word（.docx/.doc）、Excel（.xlsx）、PPT（.pptx）、PDF 和文本/代码
  都能直接拖进来问，后端转成纯文本再交给模型；单份最多取 6 万字，超出会提示截断

#### 2. 情感系统
- **先评价、再折算**：模型给出评价变量（合意/可能/该当/谁造成/能否应付/意外），
  后端按 OCC 模型折成具体情绪，再映射到 PAD——每一步都能解释
- **三层时间尺度**：这一句的情绪（emotion）/ 这一两天的心情（mood）/ 她本来是谁（人格基线）
- **心情会自己缓**：没聊天时按 18 小时半衰期往基线回落，所以"昨天吵完架今天还有点闷"是自然发生的
- **关系阶段**：初识 / 熟悉 / 亲近 / 依赖，用来约束称呼、主动程度和边界感
- **对方的情绪会累积**：连续几轮低落才算"他最近不太好"，不会一轮就下结论
- **交叉校验**：文本明显消极时，模型报的"开心"会被压回去

#### 3. 记忆系统
- **SQLite 存储**：消息一条一行（发消息 O(1)），不再整份重写 JSON
- **两种范围**：`user` 是跨对话的（名字、职业、经历），`conv` 只属于某段对话
- **新对话可选**：「继续聊」接着之前的关系与记忆；「重新认识」从零开始，也读不到旧记忆
- **写入去重**：同一事实不会记两遍；换工作这类冲突会保留旧记录（可回答"以前是做什么的"）
- **按话题检索**：本地语义向量（bge-small-zh，24MB，CPU）+ 关键词 + 重要度 + 新近度 +
  情绪相似度一起算分。字面完全不同也能对上——说"老板又发火"，能想起"和主管关系不好"
- **语义去重**：换了种说法但意思一样的合并成一条；换工作这类同槽位换值仍保留旧记录
- **反思**：批量整理时顺手沉淀 0~2 条"对他的理解"（"他嘴上说没事，其实怕拖累同事"）
- **时间线**：记忆会记下"大概哪天发生的"，能按时间拼出"你们最近这些事"
- **会遗忘**：长期没用又不重要的记忆降级归档，可恢复
- **批量摘要**：最近 26 条保留原文，更早的攒一批做一次摘要（窗口整体前移，不逐轮滑动）
- **可查看可删除**：设置 → 存储 里按「全部 / 她一直记得 / 这段对话」筛着看，每条都能删

#### 4. 视觉系统
- Live2D立绘显示
- 3个可选角色：Murasame_Yukata、nahida、yumi
- 根据对话内容自动调整表情

#### 5. 语音系统（可选）
- **逐句流式朗读**：切开句子边合成边播，第一声通常在 1 秒内（旧版要等整段合成，3~5 秒）
- **会跟着情绪变语气**：开心时语调上扬、难过时放慢、害羞时放轻。情绪来自对话里算出的 dominant_emotion + PAD，合成时转成情感标签
- **五档引擎，自动兜底**：

  | 引擎 | 声音 | 一句的延迟 | 需要 |
  | --- | --- | --- | --- |
  | 千问神经语音（推荐） | 最像真人，能带情绪 | 0.6~1.2 s | 百炼 API Key（送 11 万字符） |
  | 本地大模型（离线） | IndexTTS2 / Qwen3-TTS / Breeze / GPT-SoVITS | 0.3~2 s | 本机起个 HTTP 服务 |
  | Fish Audio S2 | 多人对话、ASMR 最强 | 1~3 s | Fish Key |
  | 在线免费（百度） | 可用，音质一般 | 0.3~0.7 s | 只要网络 |
  | 系统语音 | Huihui / Yaoyao | 0.02~0.05 s | 什么都不用 |

- **嘴型跟着声音动**：按每句音频的真实时长驱动，不是机械的循环动画
- 设置 → 语音里可以对比「平铺直叙」和「带情绪」两种念法

### 🎨 界面特性

- 「静夜书简」视觉语言：宋体标题 + 宽字距标签 + 编校式竖线，她的每句话挂在同一条织线上
- 四套气质主题：夜航 · 朝霧 · 纸白 · 曜石
- Live2D 立绘随情绪与内容变化，支持鼠标视差、轻触互动
- 轻量 Markdown 渲染（代码块 / 行内代码 / 加粗），一键复制回复
- 响应式：桌面双栏 → 平板抽屉 → 手机全屏，支持减弱动态偏好

## 🚀 快速开始

### 前置要求

- Python 3.8 或更高版本
- Windows 操作系统（推荐 Windows 10/11）
- 网络连接（如使用在线API）

### 安装步骤

#### 1. 克隆仓库

```bash
git clone https://github.com/yourusername/hoshiori-ai.git
cd hoshiori-ai
```

#### 2. 安装依赖

```bash
pip install -r requirements.txt
```

#### 3. 配置API密钥

**方法一：使用示例配置文件（推荐）**

```bash
# 复制示例配置文件
copy config.py.example config.py

# 编辑 config.py，将 YOUR_API_KEY_HERE 替换为你的API密钥
```

**方法二：在程序中配置**

首次运行程序时，点击"设置"按钮，输入你的API密钥即可。

#### 4. 运行程序

```bash
python main.py
```

### 获取API密钥

星织支持多种AI提供商，你可以选择以下任一方式：

#### 在线API（推荐新手）

1. **DeepSeek API**
   - 访问：https://platform.deepseek.com/
   - 注册账号并获取API密钥
   - 支持深度思考模式

2. **小米 MiMo API**
   - 访问：https://mimo.xiaomimimo.com/
   - 注册账号并获取API密钥
   - 多种模型可选

#### 本地模型（隐私保护）

1. 下载并安装 [LM Studio](https://lmstudio.ai/)
2. 在 LM Studio 中下载模型（推荐 Qwen2.5-7B-Instruct-GGUF）
3. 启动本地服务器（默认端口 1234）
4. 在星织中切换到"本地模式"

## ⚙️ 配置说明

### 基本配置

配置文件位于 `baocun/config.json`，主要配置项：

```json
{
  "model_mode": "online",           // 模式: "online" 或 "local"
  "api_provider": "mimo",           // 提供商: "deepseek", "mimo", "custom"
  "thinking_mode": "disabled",      // 思考模式: "enabled" 或 "disabled"
  "web_search_enabled": false,      // 联网搜索: true 或 false
  "online_api_key": "YOUR_API_KEY", // 在线API密钥
  "show_avatar": true               // 显示立绘: true 或 false
}
```

### 高级配置

#### 切换AI提供商

在程序界面点击"设置"按钮，选择不同的API提供商：
- DeepSeek：支持深度思考，适合复杂推理
- 小米MiMo：多种模型，性价比高
- 自定义：支持任何兼容OpenAI格式的API

#### 启用深度思考模式

深度思考模式会让AI进行更深入的推理，适合复杂问题：
1. 打开设置
2. 选择"开启深度思考"
3. 注意：会增加Token消耗和响应时间

#### 启用联网搜索

让星织能够搜索互联网获取最新信息：
1. 打开设置
2. 启用"联网搜索"
3. 目前仅支持部分模型

### 本地模型配置

#### LM Studio 设置

1. **下载模型**
   - 推荐模型：Qwen2.5-7B-Instruct-GGUF
   - 量化版本：Q4_K_M（4.3GB）或 Q5_K_M（5.2GB）

2. **加载模型**
   - GPU Offload：拉满（Max）
   - Context Length：8192 tokens
   - Temperature：无需设置（代码中已优化）

3. **启动服务器**
   - 切换到"Local Server"标签
   - 点击"Start Server"
   - 确认端口为 1234

#### 性能建议

| 配置 | 推荐模型 | 显存占用 | 性能 |
|------|----------|----------|------|
| 8GB 显存 | Q4_K_M | ~5GB | 优秀 |
| 12GB+ 显存 | Q5_K_M | ~6GB | 极佳 |
| 无显卡 | 不推荐本地模型 | - | - |

### 改前端时提示"文件被占用 / 权限不足"

主窗口是 WebView2。如果上一次是崩溃退出或者被任务管理器强杀的，
`msedgewebview2.exe` 会留在后台，握着页面文件的句柄——这时的报错是
`Permission denied`，但文件属性、ACL、`os.access` 全都说可写，
很容易查错方向。

```bash
python main.py --unlock      # 或者 python runtime_guard.py
```

它会列出相关的窗口进程、标出哪个是孤儿，然后清掉。正常情况下不用管，
程序启动和退出都已经自动处理了。
