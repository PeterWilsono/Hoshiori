    📦 Live2D模型文件夹
═══════════════════════════════════════════════════════════

请将你的Live2D模型文件放在这个文件夹中。

需要的文件：
├── model3.json          # 模型配置文件（必需）
├── model.moc3           # 模型数据文件（必需）
├── textures/            # 贴图文件夹
│   └── texture_00.png   # 贴图文件
├── motions/             # 动作文件夹（可选）
└── expressions/         # 表情文件夹（可选）

获取免费模型：
1. Live2D官方示例：https://www.live2d.com/download/sample-data/
2. Booth免费模型：https://booth.pm/ 搜索"Live2D フリー"

详细说明请查看：Live2D动态立绘-准备指南.md
